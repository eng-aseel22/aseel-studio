# ستديو الأسيل للتصوير

## توثيق أجمل اللحظات

هذا المشروع عبارة عن صفحة ويب بسيطة لـ "ستديو الأسيل للتصوير"، تهدف إلى عرض الخدمات المقدمة وتوفير نموذج حجز سهل للعملاء. تم تطوير المشروع باستخدام HTML و CSS و JavaScript، مع التركيز على تصميم جذاب وسهل الاستخدام.

## الميزات الرئيسية

*   **تصميم متجاوب:** يعمل الموقع بشكل جيد على مختلف أحجام الشاشات والأجهزة.
*   **عرض الخدمات:** قسم مخصص لعرض أنواع التصوير المختلفة (خريجين، أطفال، كابلز).
*   **نموذج حجز:** نموذج بسيط وسهل لطلب حجز جلسة تصوير مع رسالة تأكيد فورية.
*   **تأثيرات بصرية:** استخدام CSS لتحسين تجربة المستخدم وجاذبية الموقع.

## التقنيات المستخدمة

*   **HTML5:** لبناء هيكل الصفحة.
*   **CSS3:** لتصميم وتنسيق العناصر البصرية.
*   **JavaScript:** لإضافة التفاعل إلى نموذج الحجز.

## كيفية تشغيل المشروع محلياً

لفتح المشروع على جهازك المحلي، اتبع الخطوات التالية:

1.  **استنساخ المستودع (Clone the repository):**
    ```bash
    git clone <رابط المستودع الخاص بك على GitHub>
    ```
2.  **الانتقال إلى مجلد المشروع:**
    ```bash
    cd aseel-studio
    ```
3.  **فتح الملف:** افتح ملف `index.html` في متصفح الويب المفضل لديك.

## استخدام Git و GitHub (لأغراض الواجب)

تم إعداد هذا المشروع ليعكس أفضل الممارسات في استخدام Git و GitHub، وهو يتضمن:

*   **Commits منظمة:** رسائل Commits واضحة وموجزة تصف التغييرات.
*   **Branches:** استخدام فروع للميزات (feature branches) لعمليات التطوير.
*   **Pull Requests:** سيتم شرح كيفية إنشاء Pull Request لدمج التغييرات.
*   **Issues:** سيتم شرح كيفية استخدام Issues لتتبع المهام والأخطاء.

### مثال على سير عمل Git:

1.  **إنشاء فرع جديد للميزة:**
    ```bash
    git checkout -b feature/new-feature-name
    ```
2.  **القيام بالتغييرات وحفظها (Commit):**
    ```bash
    git add .
    git commit -m "feat: add new feature description"
    ```
3.  **العودة إلى الفرع الرئيسي ودمج التغييرات:**
    ```bash
    git checkout master
    git merge feature/new-feature-name
    git branch -d feature/new-feature-name # حذف الفرع بعد الدمج
    ```
